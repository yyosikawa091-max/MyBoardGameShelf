# MyBoardGameShelf
ボドゲをまとめるサイト

## 公開サイト

GitHub Pages で公開中です。`main` ブランチへの push 後にサイトへ反映されます。

https://yyosikawa091-max.github.io/MyBoardGameShelf/

ゲームの追加・編集内容は利用中のブラウザーに保存され、端末間では同期されません。

写真を登録していないゲームは、カードが画面に表示されたときにWikimedia Commonsでゲーム名と「board game」を検索し、最初に見つかった画像を表示します。検索結果と作者・ライセンスのクレジットは利用中のブラウザーに保存されます。フォームから写真を選んだ場合は、その写真が自動検索画像より優先されます。検索画像は箱絵とは限らず、検索結果がない場合は従来の画像検索表示を使います。
